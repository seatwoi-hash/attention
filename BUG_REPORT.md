## Ответы: три найденные ошибки

Номера строк ниже отсчитываются с 1 внутри ячейки «Код с подсаженными ошибками».
Исходный прогон: **пройдено 7 из 17**. Полный результат после исправлений находится в ячейке «Прогон» ноутбука `notebooks/dz1-bughunt.ipynb`. Код проверок сохранён без изменений.

| # | Функция и строка | Механизм поломки | Как исправили |
|---|---|---|---|
| 1 | `sinusoidal_positional_encoding`, строка 39: `position = ...` | Индексы начинались с 1: токен на позиции 0 получал код позиции 1, а остальные — код следующей позиции. Поэтому первая строка содержала `sin(w)` и `cos(w)` вместо нулей и единиц. Это сдвиг фазы синусоид по всем абсолютным позициям и нарушение заданной формулы; сам по себе он не означает, что модель не сможет обучаться. | Заменено `torch.arange(1, length + 1, ...)` на `torch.arange(length, ...)`: позиции теперь от 0 до `length - 1`. |
| 2 | `LayerNorm.forward`, строки 60–61: `mean` и `var` | Статистики считались по оси батча (`dim=0`) для каждой позиции и канала. Представление одного примера зависело от других примеров; признаки отдельного токена не нормировались. При батче из одного примера среднее совпадало с входом, дисперсия была нулевой и нормализованная часть полностью обнулялась. | В вычислении среднего и дисперсии установлено `dim=-1`. Статистики теперь считаются по признакам каждого токена независимо; `keepdim=True` и `unbiased=False` сохранены. |
| 3 | `scaled_dot_product_attention`, строка 101: `weights = ...` | `softmax(dim=-2)` нормировал оценки по запросам, а не по ключам: единице равнялась сумма столбца, а строка переставала быть распределением по доступным значениям. Кроме того, знаменатель для веса текущего запроса включал оценки будущих запросов. Поэтому даже при нулях выше диагонали будущие токены могли влиять на прошлые выходы через нормировку. | Установлено `softmax(scores, dim=-1)`: каждый запрос получает распределение по ключам своей строки. Причинная маска применяется до softmax, так что будущие позиции исключены из этой нормировки. |

После исправлений в ноутбуке выполнены все 600 шагов обучения на исходном игрушечном корпусе, построена кривая потерь и сохранён пример генерации. Это демонстрация обучения на повторяющемся шаблоне, а не оценка обобщения на новом тексте.

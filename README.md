# ДЗ 1 «Внимание своими руками»

## Содержимое

- `notebooks/dz1-attention.ipynb` — четыре реализованные функции, вывод 17 проверок и личный ответ о маске перед softmax.
- `notebooks/dz1-bughunt.ipynb` — три исправленных бага, таблица объяснений, вывод 17 проверок, обучение на 600 шагах, график и генерация.
- `BUG_REPORT.md` — отдельный табличный отчёт: локализация, механизм и исправление каждой ошибки.
- `results/loss.png` — график потерь, извлечённый из выполненного ноутбука.
- `results/generated_text.txt` — фактический результат генерации.
- `results/attention-checks.txt`, `results/bughunt-checks.txt`, `results/training.txt` — вывод проверок и обучения.
- `requirements.txt` — версии основных зависимостей; `environment.txt` — сведения о проверенном окружении и полный список установленных пакетов.
- `run_notebooks.py` — выполнение обоих ноутбуков с чистыми ядрами и проверкой результатов.

## Воспроизведение локально с нуля

Нужен установленный Python 3.12. Проверенный прогон выполнен на Python 3.12.16, macOS 26.2 arm64, CPU, с одним потоком OpenMP/MKL. Тестовые ячейки не изменялись.

Распакуйте архив и откройте терминал в папке, где находится этот README. Создайте отдельное окружение:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python run_notebooks.py
```

На Windows после создания окружения используйте `.venv\Scripts\activate` вместо `source .venv/bin/activate`; название установленной команды Python может отличаться.

Скрипт запускает оба ноутбука сверху вниз в отдельных ядрах, сохраняет вывод в `.ipynb`, обновляет файлы `results/` и завершится ошибкой при падении ячейки или отсутствии сообщения `пройдено 17 из 17`. Прогон включает все 600 шагов обучения; время зависит от оборудования.

## Запуск в Google Colab

1. Загрузите `notebooks/dz1-attention.ipynb` в Google Colab.
2. В настройках среды выполнения выберите Python и ускоритель T4, как требует условие курса.
3. Выполните все ячейки сверху вниз. Ожидается `пройдено 17 из 17`.
4. В отдельном сеансе повторите это для `notebooks/dz1-bughunt.ipynb`; дождитесь окончания обучения, графика и генерации.
5. Скачайте оба выполненных ноутбука, сохранив вывод. Первая кодовая ячейка печатает Python, PyTorch, платформу и начальный seed.

В предоставленной реализации данные и модель по умолчанию остаются на CPU даже в среде с T4; это сохранено. Проверенный здесь прогон — CPU на macOS, реальный запуск в Google Colab/T4 не выполнялся. Для подтверждения требования именно к этой среде нужно выполнить указанный прогон в Colab. Побитовое совпадение результатов на другой платформе или с другими версиями библиотек не утверждается.

Для интерактивного запуска нужны `torch` и `matplotlib`; первая ячейка устанавливает `torch`, если его нет. Если отсутствует matplotlib, выполните отдельную ячейку `%pip install matplotlib`. Зависимости `nbclient` и `nbformat` нужны для автоматического локального запуска, а не для самой модели.

## Seed и конфигурация эксперимента

Seed варианта с подсаженными ошибками — **42**. В первой кодовой ячейке обоих ноутбуков также фиксируется начальное состояние генератора: `torch.manual_seed(42)`.

Само обучение в `dz1-bughunt.ipynb` отдельно вызывает **`torch.manual_seed(0)`** до создания модели и выборки батчей. Исходные тесты сохраняют свои внутренние seed от 0 до 7. Генерация выполняется сразу после обучения из полученного состояния генератора; для повторения нужно запускать ноутбук целиком с чистого ядра, а не только последнюю ячейку.

| Параметр | Значение |
|---|---|
| Корпус | `'алгоритм внимания смотрит на все позиции сразу. ' * 200` |
| Токенизация | Посимвольная, словарь `sorted(set(text))` |
| Размер словаря | 19 |
| Контекст | 64 токена |
| `d_model` / голов / слоёв / `d_ff` | 128 / 4 / 2 / 512 |
| Обучаемых параметров | 400 640 |
| Dropout | 0.1 |
| Оптимизатор | AdamW, `lr=3e-4`, прочие параметры по умолчанию PyTorch 2.15.0 |
| Батч / шагов | 32 / 600 |
| Цель | Предсказание следующего символа, cross entropy |
| Генерация | Начало `а`, 200 новых символов, `temperature=0.8`, `top_k=10` |

## Полученный результат

В обоих ноутбуках прошли **17 из 17 проверок**. До исправления второй ноутбук проходил 7 из 17.

В сохранённом CPU-прогоне потери обучения снизились с **3.184 до 0.037**. График и фактический текст находятся в `results/` и внутри второго ноутбука. Модель воспроизводит структуру повторяющегося русского шаблона. Это демонстрация обучения на игрушечном корпусе; отдельная оценка обобщения на отложенных данных не проводилась.

Ориентиры в общем описании задания (62 символа, 107 тысяч параметров, 500 шагов, английский текст) относятся к другому эксперименту. В выданном ноутбуке заданы 19 символов, 400 640 параметров и 600 шагов, поэтому численные значения loss и язык генерации отличаются. Корпус, архитектура, длительность обучения и параметры генерации сохранены из выданного файла.
